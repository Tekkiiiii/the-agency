# Context pressure

The harness auto-summarizes long context; no manual /compact nudging. Agents learn their own fill from `CONTEXT_PCT_ALERT` lines appended to tool results (agent-ctx mod). Main session (% of its window): 70/75% warn, 80% mandatory `/save-state` + `/respawn-self`. Subagents (any agentId != main, ABSOLUTE tokens): 200k warn; 250k finish the current task, no new work; 300k mandatory (PD: `/respawn-self`; Coord: `/save-state` then `/coord-respawn-self`; Exec: write the final report and stop). From 300k a STOP line rides EVERY tool result until the agent ends (nothing is denied). Controllers (PD/Coord) see `CHILD_CTX: <label> <K>k/300k (<pct>%)` trailing Agent tool results and SendMessage replies (label = child name, else spawn description, else agentId), and a push line on their next tool result when a live child crosses 250k/300k: `CHILD_CTX_ALERT: <label> <K>k/300k — finish current task` (parent: SendMessage the child "finish and report") or `... — must stop, request report now` (300k: Coord/PD requests the report and respawns the role if work remains). Full spec: `{agency-root}/runbooks/respawn-contract.md`. Retention policy and rollback threshold: `{agency-root}/runbooks/context-pressure-management.md`; respawn rules: `{agency-root}/runbooks/respawn-contract.md`.
